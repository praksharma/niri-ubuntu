# niri-ubuntu

A Ubuntu 24.04 (Noble) focused setup for the Niri Wayland compositor.

## Goals

- Provide a clean Niri-based setup for Ubuntu 24.04 LTS
- Avoid heavy dependencies that require newer Qt versions

## Scope

This project focuses on:

- Niri
- session setup
- sensible defaults
- lightweight Wayland utilities

This project does not aim to ship a full Qt/Quickshell-based desktop shell.
